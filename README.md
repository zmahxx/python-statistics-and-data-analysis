# Python Statistics and Data Analysis

A UTSA coursework script that simulates 100,000 experiments of 16 fair coin tosses, compares an empirical cumulative distribution with SciPy's binomial CDF, computes sums of squared errors for candidate linear models, and fits a least-squares line to a small sales example.

## Student contribution and starter materials

I wrote most of the substantive implementation. The recovered source archive contains the completed Python script, but no separate instructor starter file or template. The retained records do not support a line-by-line attribution claim. Some coursework used instructor-provided starter materials or templates; no standalone instructor source is included in this repository.

## Files and dependencies

- source/HW4_coin_toss_simulation.py — the available assignment source.
- Python, NumPy, Matplotlib, and SciPy are imported by the script.

The same completed script appeared in two locations in the source archive and is included once here. The disease-analysis notebooks and the Measles.csv and Mumps.csv files are not included. This repository does not claim to contain that disease-data analysis.

## Running and limitations

Install compatible NumPy, Matplotlib, and SciPy versions, then run:

    python source/HW4_coin_toss_simulation.py

This opens interactive Matplotlib windows. The script has not been executed or validated for this release review. It uses a fixed random seed. No open-source license is included.
